# Size & Fit Calculators

A size and fit calculator helps customers choose the right size before they buy. Options range from a short questionnaire ("What size do you wear in Brand X?") to tools that estimate body measurements. For apparel and footwear, solving sizing is one of the most useful improvements you can make to the product page, because it affects both conversion and returns.

## How it works

Sizing uncertainty is a major barrier to buying clothes and shoes online. Customers know their size in one brand but not in yours, and most will not translate a size chart from centimeters. A calculator turns what they already know (their size elsewhere, height, weight, fit preference) into a specific recommendation. That confidence leads to purchases and reduces "buy two sizes, return one."

## How to do it

1. Choose a calculator type. Use cross-brand size matching for basics, body measurements for tailored or technical items, and a third-party fit tool for higher-priced products where return savings justify the cost.
2. Place the tool directly next to the size selector, visible without scrolling. On mobile, open it as an overlay on the same page.
3. Calibrate recommendations per product using return reasons, fit comments in reviews, and garment measurements. If an item runs small, recommend one size up for that item.
4. Show the basis for the recommendation, for example "Most customers with your measurements chose Medium." Use only real data.
5. Store calculator inputs and use them for planning: which sizes are under-stocked and whether your size grading needs adjusting.

## What to measure

- **Calculator usage rate**: product page visitors who use the calculator divided by all visitors to sized products.
- **Recommendation-to-cart rate**: add-to-cart rate for calculator users compared with non-users.
- **Size-related return rate**: "wrong size" returns as a share of orders, for calculator users vs. non-users.

## Best practices

- Use review data in the recommendation ("Customers of similar height and weight say this fits true to size").
- When a result falls between sizes, recommend both and explain the difference ("Medium for a fitted look, Large for a relaxed fit").
- Save the customer's size profile so returning customers see their size automatically.
- Pair the calculator with a fit promise, such as free return shipping if the recommended size does not fit.

## Common pitfalls

- Calling a static size chart a calculator. Most customers do not know their measurements. The tool must translate what they do know.
- Ignoring product-level fit. A slim-fit shirt and an oversized hoodie need different recommendations.
- Hiding the tool. If it is buried behind several clicks, few people will use it.
