# Buy-the-Set Collections

A set is a pre-selected group of related products sold together at a set price or bundle discount: a skincare routine, a cookware collection, a hobby starter kit. Unlike build-your-own bundles, the brand picks the products and presents the set as its recommended combination. Sets give new customers an easy place to start.

## How it works

Sets reduce choice overload. A shopper facing 30 skincare products may not know which cleanser, serum, or moisturizer to buy. A set called "The Complete Morning Routine" answers that for them. The brand's recommendation turns browsing into buying. Even a modest discount feels like a smart purchase because someone has already put the combination together.

## How to do it

1. Find products that are often bought together in your order data.
2. Group them into clear sets: by routine (morning, evening), by level (beginner, advanced), by occasion (travel, gift, season), or as a complete solution for one job.
3. Price the set below the sum of its parts and show both numbers so the savings is visible.
4. For premium sets, consider better packaging instead of a deeper discount.
5. Give each set its own product page: a photo of all items together, a short section on each item, why they work together, how to use them in order, and reviews from set buyers.
6. Show sets first to new visitors: above individual products on category pages and as the first recommendation in welcome emails.
7. Release limited seasonal or gift sets with a clear end date.

## What to measure

- **Set revenue share**: revenue from sets divided by total revenue.
- **Set AOV vs. single-item AOV**: average order value of set orders compared with single-product orders.
- **Set-to-individual repurchase rate**: share of set buyers who later buy individual products.

## Best practices

- Name sets by outcome, not contents. "The Glow Routine" says more than "Cleanser + Serum + Moisturizer Set."
- Anchor each set with one best seller and add a few products customers might not have found on their own.
- Use set-specific packaging so the set feels like one product.
- Show the products being used together in a photo or short video.

## Common pitfalls

- Too many overlapping sets. If five sets share the same moisturizer, customers cannot tell them apart. Give each set one clear purpose.
- Only offering expensive sets. Include a lower-priced starter set for first-time buyers.
- Not updating sets when products change. If an item is reformulated or sold out, update the set page right away. Do not ship substitutions without telling the customer.
